Paragraph Examples

HTML is the standard language used to create web pages. The chemical formula for water is H2O and 102 equals 100. This text is inside a span element.

Web development involves creating interactive websites. The value x2 represents x squared, while CO2 represents carbon dioxide. This is another span element.

CSS is used to style HTML documents and improve their appearance. For example, x3 represents x cubed and H2O represents water. Span can be used to group inline content.

JavaScript adds functionality to websites and makes them more interactive. The expression 52 equals 25, while O2 represents oxygen. This is a span element.

HTML elements help organize a webpage, while attributes provide additional information about elements. The mathematical expression x2 is an example of superscript, while H2O uses subscript. Inline text can also be grouped using span.
